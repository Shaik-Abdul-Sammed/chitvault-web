# ChitVault Web

> Every payment. Every winner. Secured.

Landing page for **ChitVault** — a record-keeping and communication tool for chit fund and committee managers in India.

**Live:** https://shaik-abdul-sammed.github.io/chitvault-web/

---

## About

Single-file marketing landing page for the ChitVault Android app. Designed to convert visitors into demo requests with one tap on WhatsApp.

## Features

- Sticky navigation with always-visible CTAs
- Animated gradient hero
- Trust bar with 4 differentiators
- 6 feature cards with hover effects
- 3-step how-it-works flow
- 11-language showcase
- Native FAQ accordion
- Legal disclaimer block
- Clickable WhatsApp and email
- Fully responsive 320px to 4K
- Zero JavaScript
- Zero dependencies
- About 15 KB total

## Tech Stack

| Layer | Technology |
